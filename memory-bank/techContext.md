# Tech Context

## Technologies Used

- Django (Python) for backend
- Django REST Framework for API
- Vue.js (with TypeScript) for frontend
- Vuex for state management
- Charting libraries (e.g., Chart.js, ECharts)
- PostgreSQL (assumed for production DB)

## Development Setup

- Python/Poetry for backend dependency management
- Node.js/NPM for frontend
- Local development with .env configuration
- Modular codebase for both backend and frontend

## Technical Constraints

- Secure handling of user data and authentication
- Scalability for future asset classes and features
- Consistent API design for frontend-backend integration

## Dependencies

- Django, djangorestframework, psycopg2 (or similar for PostgreSQL)
- Vue.js, vuex, vue-router, charting libraries
- Axios or similar for API calls
